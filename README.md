# 💌 Taklifnoma — Uchrashuvga Taklif Sahifasi

Qiziqarli, interaktiv "uchrashuvga taklif" veb-sahifasi. Foydalanuvchi ism/familiya kiritadi, taklif chiqadi — agar **"Yo'q"** tugmasi bosilsa, u joyidan qochib, ustiga hazil gaplar yozib chiqadi. **"Ha"** bosilsa esa faoliyat turi (kino, sayr, bog'da aylanish), sana va vaqt tanlanadi hamda taklif "jo'natiladi".

## ✨ Xususiyatlar

- 💗 Pushti (pink) rangdagi, qizlarga mos, oddiy va zamonaviy dizayn
- 🙈 "Yo'q" tugmasi bosilganda joyidan qochadi va matni o'zgaradi ("Aniqmi?", "Rostanmi?", "O'ylab ko'ring", "Nega?" va h.k.)
- 🎬 Faoliyat tanlash: Kino / Sayr / Bog'da aylanish
- 📅 Sana va ⏰ vaqt tanlash imkoniyati
- 📱 Mobil qurilmalarga moslashgan (responsive)
- ⚡ Hech qanday tashqi kutubxonasiz — sof HTML, CSS va JavaScript

## 📁 Loyiha tuzilishi

```
├── index.html   # Sahifa tuzilishi (HTML)
├── style.css    # Dizayn va stillar (CSS)
└── script.js    # Interaktiv funksiyalar (JavaScript)
```

## 🚀 Ishga tushirish

1. Repozitoriyani yuklab oling yoki klonlang:
   ```bash
   git clone https://github.com/USERNAME/taklifnoma.git
   ```
2. `index.html` faylini istalgan brauzerda oching — hech qanday qo'shimcha o'rnatish shart emas.

Yoki **GitHub Pages** orqali onlayn joylashtirish uchun:
1. Repozitoriya sozlamalariga o'ting: **Settings → Pages**
2. **Source** qismida `main` branch va `/root` papkasini tanlang
3. Bir necha daqiqadan so'ng sahifa `https://USERNAME.github.io/taklifnoma/` manzilida ishga tushadi

## 🛠 Ishlatilgan texnologiyalar

- HTML5
- CSS3 (flexbox, animatsiyalar, gradient)
- Vanilla JavaScript (kutubxonasiz)

## 📄 Litsenziya

Ushbu loyiha shaxsiy va o'quv maqsadlarida erkin foydalanish uchun ochiq.
